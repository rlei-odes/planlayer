# Architecture decision records

One file per decision: `NNNN-short-title.md`, numbered in order, starting from [0000-template.md](0000-template.md). A backlog item `D-nn` is done when its ADR is merged, and the ADR names the item it closes.

An ADR records the decision and the reasons for it, and the consequences that follow. When a decision changes, a new ADR supersedes the old one, and the old one gets a "Superseded by" line. Decisions that need no discussion are recorded in the decisions table of [BACKLOG.md](../../BACKLOG.md) instead.
